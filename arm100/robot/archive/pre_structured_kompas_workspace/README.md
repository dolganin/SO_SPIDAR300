# КОМПАС-3D: исходный рабочий набор

Точка входа: `SO101 Assembly.a3d`.

В этой папке находятся все `.a3d` и `.m3d`, которые образуют дерево внешних
ссылок основной сборки: собственные узлы SO-101, сервоприводы, плата Bus Servo
Adapter, крепёж и библиотечные компоненты. Большая часть имён создана импортом
из исходной CAD-сборки и потому не является человекочитаемой.

Папка оставлена плоской специально: ссылки внутри `.a3d` используют имена
соседних файлов. Не перемещайте отдельные файлы без перепривязки в КОМПАС-3D.
Готовые для обычного использования STEP-файлы находятся уровнем выше в
`../01_assembly` и `../02_exports/step`.
