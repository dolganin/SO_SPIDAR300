# SO-101 — рабочая структура

Эта папка содержит только рабочие исходники КОМПАС-3D, локальные варианты и
архив служебных файлов. STEP-модели, SO-100, крепёж и держатели проводки были
намеренно удалены.

## Куда идти

| Папка | Назначение |
| --- | --- |
| `03_kompas_workspace` | Редактируемый проект КОМПАС-3D, разложенный по узлам. Начинать с `00_assembly/SO101 Assembly.a3d`. |
| `04_wip` | Незавершённые локальные варианты: `Base_ARM`, `Cubic`, `Коробочка` и альтернативный держатель основания. Эти файлы не входят в основную сборку. |
| `90_archive` | Резервные копии `.bak`, временные файлы `~$*`, журналы и прежние логи. Не использовать как источник актуальной модели. |

## Правило для КОМПАС-3D

Пути в `Sources` у всех сборок были переписаны для этой структуры. Переносить
отдельные файлы после этого всё равно нельзя: при необходимости нового
перемещения надо снова перепривязать ссылки в КОМПАС-3D либо обновить все
зависящие сборки.

## Типы файлов

- `.a3d` — сборки/компоненты КОМПАС-3D;
- `.m3d` — детали и служебные компоненты КОМПАС-3D;
