# КОМПАС-3D: исходный рабочий набор SO-101

Точка входа: `00_assembly/SO101 Assembly.a3d`.

## Карта модели

- `00_assembly` — верхняя сборка манипулятора;
- `10_mechanical` — база и структура, звенья, запястье, захват и монтажные
  пластины;
- `20_hardware` — сервоприводы;
- `30_electronics/bus_servo_adapter` — плата адаптера и её электронные
  компоненты.

Все пути в XML-потоках `Sources` были переназначены на эту иерархию. Файл
`LINK_REWRITE_REPORT.txt` фиксирует две внешние ссылки на винты, которых не
было в исходной папке. Они не изменялись.

До изменения структуры исходный плоский набор был сохранён в
`../90_archive/pre_structured_kompas_workspace`; из него также удалены
намеренно исключённые крепёж и держатели проводки.
